# 참가자 메시지를 구글 스프레드시트로 관리하기

시트에 한 줄 적으면 사이트에 그대로 뜹니다. 지우면 사라집니다.
코딩 지식 없이 10분이면 끝나고, **한 번만** 설정하면 됩니다.

---

## 1. 스프레드시트 만들기

[sheets.new](https://sheets.new) 로 새 스프레드시트를 만들고 이름을 정합니다. 예: `핑크런 참가자 메시지`

---

## 2. Apps Script 붙여넣기

1. 상단 메뉴 **확장 프로그램 → Apps Script**
2. 편집기에 있던 기본 코드(`function myFunction() {}`)를 **전부 지웁니다**
3. 이 폴더의 **`Code.gs`** 내용을 전부 복사해 붙여넣고 저장 (⌘S)

---

## 3. 시트 틀 만들기 (선택, 하면 편합니다)

Apps Script 편집기 위쪽 함수 목록에서 **`setupSheet`** 를 고르고 **▶ 실행**.
권한 승인 창이 뜨면 허용합니다. `messages` 시트가 헤더와 예시 2줄이 채워진 채로 만들어집니다.

직접 만드셔도 됩니다. 시트 이름은 **`messages`**, 1행은 헤더로 두고 아래처럼 4칸을 씁니다.

| A · 이름 | B · 참가유형 | C · 메시지 | D · 표시 |
|---|---|---|---|
| 김마켄 | 2025 러너 | 가족과 함께 걸으며 나눈 이야기가 오래 남았습니다. | TRUE |
| 이핑크 | 마켄 가족 | 처음엔 회사 행사였지만 결승선에선 모두 한 팀이었어요. | TRUE |

---

## 4. 웹앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴 → **웹 앱** 선택
3. 아래처럼 설정

   | 항목 | 값 |
   |---|---|
   | 다음 사용자로 실행 | **나** |
   | 액세스 권한이 있는 사용자 | **모든 사용자** |

4. **배포** → 권한 승인
   - "이 앱은 확인되지 않았습니다" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동**. 본인이 만든 스크립트라 안전합니다.
5. 나오는 **웹 앱 URL** 을 복사합니다 (`https://script.google.com/macros/s/AKfycb.../exec`)

> 여기서 **모든 사용자** 로 두지 않으면 사이트에서 메시지를 못 읽습니다. 이 URL로는 시트를 수정할 수 없고 읽기만 가능하니 안전합니다.

---

## 5. 사이트에 URL 넣기

`pinkrun-site/js/config.js` 를 열어 붙여넣습니다.

```js
window.PINKRUN_CONFIG = {
  apiUrl: "https://script.google.com/macros/s/AKfycb....../exec",
  applyUrl: "https://form.naver.com/response/wOOcuNdggA"
};
```

저장하고 사이트를 새로고침하면 메시지가 뜹니다. **이 단계는 한 번만 하면 됩니다.**

---

## 사용법

이제부터는 **스프레드시트만 만지면 됩니다.**

- **추가** — 맨 아래 줄에 이름·참가유형·메시지를 적습니다. 사이트 새로고침하면 나타납니다.
- **수정** — 칸 내용을 고칩니다.
- **삭제** — 행을 지우거나, D열(표시)에 `FALSE` 를 적습니다. `FALSE` 로 두면 시트에는 남고 사이트에서만 숨겨집니다.
- **순서** — 시트에서 아래에 있는 메시지가 사이트 맨 앞에 옵니다. 즉 새로 적은 게 위로 갑니다.
- **참가유형은 비워도 됩니다.** 비우면 이름만 표시됩니다.
- **이름을 비우면** "참가자" 로 표시됩니다.

---

## 알아두면 좋은 점

- **반영 시점** — 새로고침하면 바로 보입니다. 다만 구글이 응답을 잠깐 캐시할 수 있어 1~2분 늦을 때가 있습니다.
- **속도** — Apps Script는 첫 요청이 1~3초 걸릴 수 있습니다. "메시지를 불러오는 중…" 이 잠깐 보이는 건 정상입니다.
- **서버가 죽어도** — URL이 잘못되거나 응답이 없으면 메시지 영역이 통째로 숨겨집니다. 사이트가 깨지지 않습니다.
- **코드를 고쳤다면** — **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**. 새 배포를 만들면 URL이 바뀌니 기존 배포를 "수정"하세요.
- **줄바꿈** — 시트 칸 안에서 `⌥Enter` 로 줄을 바꿔도 사이트에서는 한 문단으로 이어집니다.
